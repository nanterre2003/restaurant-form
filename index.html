🏪 基本信息
餐厅名称 必填
中文名称 + 英文名称（如有）
餐厅 Logo 必填
高清图片格式，建议提供 PNG 或 SVG（透明背景更佳）
餐厅简介 / 品牌故事 必填
例如：主打菜系、创始背景、特色文化等，100–300 字即可
联系电话 必填
用于网站显示及顾客联系
电子邮件地址 可选
用于在线联系表单接收邮件
📍 地址与营业时间
餐厅地址 必填
完整地址，用于嵌入 Google 地图 / 百度地图
每日营业时间 必填
例如：周一至周五 11:00–22:00，周末 10:00–23:00
停车 / 交通信息 可选
附近停车场、地铁站或公交路线
🍜 菜单信息
完整菜单 必填
分类（前菜、主菜、甜点、饮品等）+ 菜名 + 价格，可提供 PDF 或 Word 文档
菜品描述 可选
每道菜的简短介绍，10–30 字即可
特殊标注 可选
例如：素食 🌱、纯素 🌿、辣度 🌶、过敏原（坚果、花生等）
📷 图片素材
菜品照片 必填
主要菜品的高清照片（越多越好，建议专业拍摄）
餐厅环境照片 必填
室内用餐区、外立面、装潢风格等
厨师 / 团队照片 可选
增加亲切感和信任度
🛒 功能需求
是否需要在线订位功能？
顾客可通过网站直接预订座位
是否需要在线点餐 / 外卖功能？
例如自建外卖系统或对接第三方平台
是否需要多语言？
例如中文 + 英文 双语网站
是否需要活动预订（宴会 / 包厢）？ 可选
适合有包厢或定制宴席服务的餐厅
🌐 网站技术设置
域名 可选
是否已购买域名？例如 www.myrestaurant.com
参考网站风格
喜欢哪些餐厅网站的设计风格？提供链接即可
品牌主色调 可选
例如：红色、黑色、金色等偏好颜色
📱 社交媒体账号
社交平台账号链接 可选
Instagram、Facebook、WeChat、Yelp、Google Business、TikTok 等
顾客评价 / 媒体报道 可选
好评截图或报道链接，可展示在网站增加信任度
